🎬 YouTube Transcript Summarizer

This Streamlit app leverages Google's Gemini Pro model to generate concise and structured summaries from YouTube video transcripts. Just paste the video link, and it returns a set of detailed notes — ideal for quick reviews, content research, or studying.
✨ Features

    Extracts full transcript from any public YouTube video

    Uses Gemini 1.5 Pro to summarize transcripts in bullet points

    Clean and simple Streamlit UI

    Secure handling of API keys with .env file

🧰 Tech Stack

    Python

    Streamlit

    Google Generative AI (Gemini Pro)

    YouTube Transcript API

    dotenv

🚀 Getting Started

    Clone the repository to your local machine.

    Create a virtual environment and activate it.

    Install the required dependencies listed in requirements.txt.

    Set up your Gemini API key inside a .env file in the root directory.

    Run the Streamlit app to access the web interface.

🔍 Example Usage

    Enter a YouTube video link in the input box.

    Click the "Get Detailed Notes" button.

    The app will display the video thumbnail, fetch the transcript, and generate a detailed summary using Gemini Pro.
